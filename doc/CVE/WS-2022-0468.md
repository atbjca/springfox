# WS-2022-0468 — Jackson 数值类型转换资源耗尽 DoS

## 基本信息

| 字段 | 值 |
|------|-----|
| **CVE 编号** | WS-2022-0468 |
| **组件** | `com.fasterxml.jackson.core:jackson-core` |
| **漏洞类型** | 拒绝服务 (DoS) |
| **CVSS v3.1** | **7.5 HIGH** |
| **CWE** | CWE-400 (Uncontrolled Resource Consumption) |

## 漏洞描述

Jackson Core 在处理数值类型转换时存在缺陷，攻击者可通过发送包含特殊构造的大数值或特殊格式数字的 JSON，导致服务端 CPU 资源耗尽或响应延迟。

## 受影响版本

- jackson-core **< 2.21.0**

## 修复版本

- jackson-core **2.21.0**

## 本项目应对措施

| 状态 | 说明 |
|------|------|
| ✅ 已修复 | 已在 `gradle.properties` 中将 Jackson 版本升级至 **2.21.4** |
